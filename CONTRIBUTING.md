# Contributing

Thank you for helping make this roadmap more useful. Contributions should improve clarity, correctness, accessibility, or practical value.

## Good contributions

Add a free and trustworthy resource with a direct link, explain who it is for, and state where it fits in the roadmap. Improve an explanation by adding a concrete example, a limitation, or a validation step. Add a project idea only when it has a clear decision, public or synthetic data path, evaluation plan, and responsible-use note.

## Quality checklist

- The link is public, relevant, and not a pirated copy.
- Claims are supported by an original source where appropriate.
- The content is understandable to a beginner without becoming inaccurate.
- Tool versions and time-sensitive details are not presented as permanent facts.
- Examples do not expose private data, credentials, or proprietary interview material.
- Markdown renders correctly on GitHub and links work.

## Pull requests

Use a focused title such as `docs: add SQL practice resource` or `roadmap: clarify level 2 gate`. Explain what changed, why it helps learners, and how you checked it. Small, focused pull requests are easier to review than broad rewrites.
