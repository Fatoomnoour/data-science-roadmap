# Free Learning Resources

Use these resources selectively. A good rule is **one primary course, one reference, and one practice source** per topic.

## Foundations

| Topic | Resource | Best use |
|---|---|---|
| Python | [Python Tutorial](https://docs.python.org/3/tutorial/) | Language fundamentals and standard library |
| Python practice | [Kaggle Learn: Python](https://www.kaggle.com/learn/python) | Short, practical exercises for data work |
| Git | [Git Documentation](https://git-scm.com/doc) | Version control concepts and reference |
| Math intuition | [Khan Academy: Statistics and Probability](https://www.khanacademy.org/math/statistics-probability) | Probability and statistics foundations |
| Linear algebra | [MIT OpenCourseWare: Linear Algebra](https://ocw.mit.edu/courses/18-06sc-linear-algebra-fall-2011/) | Lectures, exercises, and conceptual depth |

## Books and lecture notes

These are free to read online or have openly available versions. Check licensing before redistributing copies.

- [An Introduction to Statistical Learning](https://www.statlearning.com/): accessible statistical learning explanations with exercises.
- [The Elements of Statistical Learning](https://hastie.su.domains/ElemStatLearn/): deeper reference for statistical learning theory.
- [Probabilistic Machine Learning](https://probml.github.io/pml-book/): probability-first treatment of modern ML.
- [Designing Data-Intensive Applications reading notes](https://dataintensive.net/): use the official book site for the book details; do not rely on pirated copies.

## How to choose resources

Prefer original documentation for APIs, a structured course for first exposure, and exercises for retrieval practice. If two resources disagree, check the version, assumptions, and primary documentation. Record the date you completed a resource, but treat completion as a weak signal; project evidence and interview performance are stronger signals.

## Source notes

The roadmap’s learning sequence is informed by the practical course coverage in Kaggle Learn [1], the modular ML curriculum and production topics in Google’s ML Crash Course [2], the algorithm and evaluation coverage in the scikit-learn User Guide [3], and the role-oriented training plan in Microsoft Learn [4]. Amazon’s Data Science career page emphasizes translating and modeling data to support decisions and customer solutions [5], which is why this repository treats business framing and communication as core skills rather than optional extras.
